Projects

Live 3D Environment Visualizer

The goal of this capstone was to stream live camera feed into 3D environment reconstruction. I connected RGB-D video to Gaussian SLAM and built the streaming pipeline around it, including a multithreaded frame loader, smoothed depth mapping, camera tracking, and a browser viewer that updates as the scene is generated. The depth frames were generated by applying a machine learning model on individual frames as they were received. ORB-SLAM library was used for real-time camera trajectory estimation.

Python · Linux · OpenCV · Gaussian SLAM

A simple point of sale system for Gong Cha boba tea shop, web-hosted, with React interface and Express + Node backend. Database hosted on Postgres. This project evolved from an entirely Java framework, later translated to Typescript. The system was stress-tested to support 1 million user transactions within an hour.

Medical Image Classification

Convolutional neural net model research project used to distinguish tumor images across lung and breast datasets. I trained a ResNet18, then used cross-validation to compare choices like data augmentation, regularization, and LibAUC-based training. This model eventually reported a metric score of 97% AUCM loss on both datasets.

Python · PyTorch · ResNet18 · LibAUC

Y86 Processor & Linux Shell

This project, I fully wired an X86 CPU using Logism Evolution digital logical circuit builder. I modeled the full five-stage pipelined program execution able to run simple C code (multiplication and division operations, bubble sort). The second iteration of this project, I built a custom shell script executor in Linux, and was able to wire the two together to execute shell programs.

Logisim Evolution · Y86 Assembly · C++ · Linux
