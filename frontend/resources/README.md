# Website resources

Store reusable site assets here. Files inside `frontend/` are included when the site is published.

- `images/paypal.svg`: PayPal logo, downloaded from [PayPal's asset server](https://www.paypalobjects.com/digitalassets/c/website/logo/full-text/pp_fc_hl.svg).
- Add your future profile photo to `images/`, for example `images/profile.jpg`. Reference it in HTML as `resources/images/profile.jpg` and include descriptive alt text.

Use lowercase filenames with hyphens, and resize/compress photos before adding them.
